# AI Studio 회사 소개 페이지

AI Studio(AI 에이전트가 일하는 소프트웨어 개발 회사)를 소개하는 정적 웹페이지입니다. HTML + CSS로만 만들어졌고 빌드 도구가 없습니다.

> 현재 검토용 미리보기입니다. 검색 엔진에 노출되지 않도록 `noindex`가 설정되어 있습니다.

## AI 생성 결과물 표시

- 이 페이지의 이미지(로고, 히어로, 아바타, 아이콘)는 AI로 생성했습니다.
- 페이지의 문구와 구조도 AI(Claude)가 작성·구현했고, 사람이 검토·승인합니다.

## 글꼴 라이선스

본문 글꼴은 [Pretendard](https://github.com/orioncactus/pretendard)이며 SIL Open Font License 1.1로 배포됩니다. 이 페이지에는 사용된 글자만 담은 서브셋을 포함했고, 라이선스 전문은 `fonts/OFL.txt`에 있습니다.
